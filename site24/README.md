# neural-work.pro/site24 — пакет первой продажи

Содержимое:

- `index.html` — коммерческая страница на русском языке, мобильная, оффер 199 €.
- `demo.html` — 3 интерактивных демонстрационных сайта на немецком (`?type=beauty`, `?type=clean`, `?type=repair`), вымышленные, без ложных отзывов.
- `config.js` — единственное место для подключения вашего WhatsApp/email и реквизитов.
- `ADS_AND_LAUNCH.md` — предложение, рекламное объявление, строгий бюджет, обработка заявки, изготовление сайтов для покупателей.

Локальная проверка: открыть `index.html` в браузере. Для GitHub Pages скопировать эти файлы в каталог `/site24/` в репозитории `hollybest/neural-work-site`, затем адрес будет `https://neural-work.pro/site24/` после публикации.

**Важно.** Пока `config.js` не заполнен, заявка НЕ отправляется: демонстрационный режим только копирует текст и честно показывает, что контакт не настроен. Не запускать платную рекламу до привязки контактов и проверки разделов Impressum и Datenschutz.
